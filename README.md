# Escuchando-la-naturaleza
Diseño de una grabadora de audio para el estudio de aves in situ.
Presentamos al alumnado el reto de diseñar y fabricar una grabadora de audio económica y autónoma para ser instalada en un entorno natural. Fomentaremos el pensamiento ingenieril, la atención a la sostenibilidad y el respeto por el entorno.
